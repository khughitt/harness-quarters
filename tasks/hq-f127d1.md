Preserving the transcript evidence a report cites (harness, session id, 1-based line numbers) needed a hand-written script: locate each store file, copy the cited lines byte for byte, add the nearest earlier assistant message before each cited human turn so an approval stays beside its proposal, and write a row map with a per-line SHA-256 plus the whole store file's hash. Expected: a session-logs command that takes session:line citations and emits that excerpt file and map, so evidence survives store pruning without copying whole sessions.
