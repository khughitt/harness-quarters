A workflow requires coordinating a read-only capture with the live task owner. The task claim identifies an active session, but collaboration can address only descendants in the current tree, and document-session discovery returned no connected sessions. The controller had to ask the user to relay the coordination request. A supported way to contact a separately active owner, or clear capability guidance for this case, is missing.
