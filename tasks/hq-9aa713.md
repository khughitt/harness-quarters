The user's ask (2026-10-31): a hook that keeps a session from blowing past the normal range of token usage and turn counts; when it does, the agent pauses and waits for the user to review the situation. For every harness hq wires, not only Codex, where it happened. Agent's reading: a hook reads the session's running counters (model calls, input tokens, active time, compactions, children spawned, and the session tree's totals for a controller) and, past a threshold, blocks further work until the user acknowledges, with a short situation summary. Thresholds start static and move to obs's baselines (obs-59789b). The instruction side is lore's companion task. Case: sun-fbaf80's subagent-driven Codex controller (codex:01a18943-2b9d-7e50-926f-b74169571349) ran from 2026-10-29T20:04Z until the user killed it on 2026-10-31 (~46 h, one turn of ~40 h after the last human message). It made 2,196 model calls on 489M input tokens; the last-30-day median top-level Codex session makes 30 calls on 2.9M (p99 709 and 129M, from obs's index). It compacted 11 times (p90 1), spawned 109 subagents (69 of them reviews or re-reviews) and left the Codex weekly rate limit at 95%. The controller spent 25.3 h in its own inference and 20.6 h in wait_agent; of its 1,134 exec calls, 467 re-read ledgers and plans and 308 recomputed sha256s. Children: 26.8 h model, 10.6 h tools. Tests (tt runs.jsonl): 87 test-fast runs, 6.8 h; 330 test-one, 2.0 h. A live catalog acquisition took ~5 h; three resumes ended in fail: acquire. The run overrode the P0 halt sun-14f4c4 nine times on its own authority. Profiled read-only from the rollouts by claude-code:1219a183-f486-4832-ac92-170d315e5fc2; detailed case on obs-59789b.

## Scope (2026-11-01, hq survey)

Established today: Claude Code and Codex hooks can deny a PreToolUse call and block UserPromptSubmit and Stop (relay docs/api.md:355-366; live PreToolUse refusal proven by ops-c8e4d1). A Stop block makes the agent continue, so it cannot pause; the sun case was one ~40 h turn, so a turn-boundary check alone would never have fired. No hook payload carries token, model-call or compaction counts; payloads carry session_id and transcript_path. SubagentStart is wired for Codex, not Claude; no compaction hook is wired. Codex rollouts record token_count and rate_limits; Claude transcripts mark isCompactSummary. agy has SessionStart, PreToolUse (run_command) and Stop; opencode and pi have no hook path. Related: hq-21aaa3 (shelved host-wide pause signal), relay's inbox and dotfiles' resource-pressure-alert for surfacing.

Outcome: past a session's range, every further tool call in a wired harness is refused with a situation summary until the user acknowledges, across Claude Code and Codex first, with the remaining harnesses' coverage stated.

Approach: a planned design, written alongside lore-911121 (agent-visible triggers and the pause report) and obs-59789b (baselines and alarms) so the three agree on one counter set, one acknowledgement and one threshold source. Decide which counters the hook keeps itself (cheap per-session state from the events it already sees) versus reads from the rollout or obs, within relay's hook time budget; how the user acknowledges or grants more; and the static thresholds used until obs supplies baselines.

Verification: the design names a replay of the sun-fbaf80 controller rollout (codex:01a18943-2b9d-7e50-926f-b74169571349) showing where the pause fires, a false-positive count over the last 30 days of indexed sessions, and a live probe per harness that a refusal holds across the stop_hook_active retry.
