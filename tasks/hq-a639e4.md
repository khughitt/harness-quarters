Follow-up of hq-9aa713 (final review, corrective round 1). PreToolUse runs before the harness asks the user to approve a call, so a Claude Code permission prompt or a Codex escalation approval keeps the call in flight and the whole wait counts as active time; a long approval wait can pause the turn right after the user approves. ExitPlanMode was added to the user-wait tools; permission prompts need a probe first: does Claude Code fire a PermissionRequest hook event (and with what payload), and what does Codex send around an escalation approval? Then mark such calls as waiting on the user rather than in flight.
