Current assessment, 2026-10-22: [ref:brief] records the cross-unit retention question, the current code and the alternatives. obs-396637 is now done: its indexer skips transcript symlinks and tolerates vanished paths. That resolves the observed indexer abort, but not preservation of a surviving session's link. Code inspection confirms that hq's capture skips symlinks and its independent unit checks do not inventory incoming links; quarantine can make a target unavailable before final deletion. A synthetic two-unit reproduction of hq prune and its linking unit's own quarantine outcome remain open.

Wait on hq-cbcc14 for bounded fixture evidence and a recommendation, then re-scope this idea. Lean toward retaining targets referenced by surviving units; group pruning and modifying a surviving session's links need more justification. hq-3b9c4c retains strict-readiness ownership and hq-624351 retains rollout ownership. This pass authorizes no live prune or implementation of a new retention rule.

## Original captured report

Claude Code writes a subagent transcript as a symlink when a session hands a running background agent to its successor: <successor>/subagents/agent-<id>.jsonl -> <predecessor>/subagents/agent-<id>.jsonl (one live example on titan from 2026-10-21, one from 2026-09-06; 4 pairs in obs's index history). The link always points from the younger session into the older one. Capture skips symlinks and prune eligibility checks regular files only (session-archive design §3.2-3.4), so a prune that takes the older unit while the younger one stays live leaves a dangling link in a live unit. Observed consequence on 2026-09-19, when Claude Code's own 30-day cleanup did the same thing: obs index failed 7 hourly runs in a row on the dangling path. obs is fixing its side (obs-396637: a dangling or vanished path no longer aborts the run). Question for the prune design: should a unit that is the target of a link from another unit be pruned only together with, or after, the linking unit, or should prune remove or report the dangling link it creates?
