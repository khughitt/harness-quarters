Why: hq-de3e4c classifies 183 real investigation episodes, but its source anchors and aggregate counts are not a portable acceptance corpus. Turn the observed questions and mistakes into a small, reproducible set that can judge the proposed search/show reader and later evidence-labelled tracing.

Inputs: [ref:survey] for the question taxonomy, role requirements and measurement limits; [ref:episodes] for stable episode IDs and source anchors; [ref:brief] for the proposed reader. Start with E002, E008, E046, E104, E142 and E175, plus the corrected relationship cases.

Done: choose the smallest case set covering all seven question types. Each case names its surveyed episode(s), an abstract query or question independent of CLI spelling, minimal synthetic or fully sanitized native-format records, and explicit expected evidence and unavailable/unknown results. Cover both harnesses and home routing; distinguish any synthetic coverage from observed examples. Include historical outputs versus inputs, call/result pairing and content-block references, human versus injected/copied history, runtime versus creation model, child-to-parent versus parent-to-child versus SDK dispatch links, and incidental parent fields. Include hard negatives for textual mention versus work ownership and empty matches with missing/unreadable/malformed/truncated coverage. Preserve unknown outcomes rather than inventing successful answers. Aggregate questions should exercise ordinary JSON processing of reader records, not require dedicated analytic verbs. Document the case list and how to replay it in [ref:cases].

Bound: cases and fixtures only, with no dependency on private live stores when replayed. No production reader/parser implementation, shared eval runner or new eval schema. Reuse project fixture conventions; obs-abfcf9 remains the owner of shared eval records. This semantic case set complements the harness-version store samples planned by obs-f5710b. It must not change what enrolled flow-trial-1 sessions or measurement tools consume; the deferred ownership transfer is separate.

Check: independently compare expected evidence to the surveyed source anchors while available, inspect fixtures for private text/paths/identifiers, verify that fixtures alone reproduce every expected fact and negative, and run the documented just test gate. No claim about population prevalence or automated trace precision follows from these cases.
