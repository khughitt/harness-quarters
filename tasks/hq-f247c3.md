Follow-up of hq-9aa713. A session an agent launches from the shell (claude -p, codex exec, crew dispatches, cross-harness reviewers) is a new root with its own counters, and its agent-written prompt passes the genuine-prompt test, so a budget line in it would be honoured (spec Resuming and granting more, Limitation). Link such sessions to their parent by process ancestry or an inherited environment variable, so the parent's limits and pause cover them.
