A standalone rollback-patch test launches Git and calls the production patch saver with an inherited subprocess environment. Exported GIT_DIR, GIT_WORK_TREE or GIT_INDEX_FILE can therefore route fixture writes into a real repository. A separate shelf-call correction now isolates its shared sandbox, but this unchanged standalone case still needs its own owner correction. Submitted verification used a credential-free parent environment with explicit Git isolation; keep that protection until the standalone fixture builds an explicit environment and checks its repository boundaries.
