Original report (Codex, 2026-10-10): task source and brief links can remain pointed at documents removed during an ownership split; scoping must recover evidence from git history.

Why: hq's open task records name 12 repository-relative `docs/` paths, in 24 task references, that no longer exist in hq. They left in two moves: the lore split (067b5dc, "remove the verified lore sources") and the earlier extraction from tack, whose specs and plans stayed in ops, obs and tasks. Every such source or body sends a reader into `git log --diff-filter=D` before they can see the evidence. The registry already uses a cross-project form, `<prefix>:docs/...` (for example `obs:docs/reports/...` and `material:docs/specs/...` in other projects' sources), so these references can point at the documents' current owners.

Done: in every open hq task (idea, todo, doing, blocked, shelved), each `source` field or body mention of a `docs/` path that is missing from hq is rewritten as `<owner>:<path>`. Notes are append-only and stay as written. Closed tasks are history and stay too. Verify by rerunning the scan below; it prints nothing.

Where each missing path lives now (checked 2026-10-10 against the sibling checkouts):
- lore: docs/notes/2026-09-21-flow-gates-brief.md (hq-756baa source; hq-619958, hq-9dfba9, hq-da52b7), 2026-09-27-path-mistakes-brief.md (hq-e2ed51 source), 2026-09-27-waiting-loops-brief.md (hq-339fdf source), 2026-09-29-cross-harness-review-brief.md (hq-67d253 source; hq-91e028, hq-c437b4, hq-dd66c1, hq-b2291c), 2026-09-29-session-store-retention-brief.md (hq-1a3278 source; hq-401088), 2026-10-02-agent-working-docs-brief.md (hq-d7b5b2, hq-fa8757 sources; hq-fed9db), 2026-10-02-codex-model-identity-brief.md (hq-fce47e, hq-1bd166 sources; hq-52ac05)
- ops: docs/specs/2026-09-16-relay-design.md and docs/plans/2026-09-16-relay-bootstrap.md (hq-539508)
- obs: docs/specs/2026-10-07-follow-renamed-projects-design.md (hq-e4e58a)
- tasks: docs/notes/2026-10-08-claim-guard-acceptance.md (hq-ee69d9), docs/notes/2026-10-08-claim-guard-execution-ledger.md (hq-3cdd68)

Check the owner before each edit, because a later move may have changed it: `ls -d ~/d/*/<path>`. When a path is found in no checkout, write the commit that removed it from hq (`git log --diff-filter=D -1 -- <path>`) beside the path instead of an owner.

Scan (from the hq root; a mention already in the `<prefix>:docs/...` form is excluded):
for f in tasks/hq-*.md; do st=$(grep -m1 '^status:' $f|cut -d' ' -f2); case $st in done|dropped) continue;; esac; for p in $(grep -oE '(^|[^:a-z])docs/(notes|specs|plans)/[A-Za-z0-9._-]+\.md' $f | sed -E 's/^[^d]//' | sort -u); do [ -e "$p" ] || echo "$(basename $f .md) $p"; done; done

Out of scope: moving these documents back into hq, and a general link checker. `source` is opaque to the tasks CLI, and no open task's `spec` or `plan` field dangles.
