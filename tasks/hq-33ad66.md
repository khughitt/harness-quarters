Follow-up of hq-9aa713 (Task 6). The per-call Python hook measures p50 31-33 ms and p99 47-48 ms in four of five 500-run sets, 65 ms under host load, against the spec's 50 ms p99 target; the floor is about 31 ms (interpreter start and json import). A resident process behind a thin client would clear the target with margin but is a host service, so it needs the user's approval. Decide after activation whether the measured latency is noticeable in practice.
