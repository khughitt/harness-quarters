On europa, interactive zsh loads nvm (default v25.6.1, npm 11.9.0). npm 11.9.0's reify never passes _isRoot to pacote, so npm ci --allow-git=root refuses even the root's direct Git dependency (EALLOWGIT, reproduced locally with npm 11.9.0; npm 12.2.1 succeeds). The recipe already reads the pin with /usr/bin/node and relay/bin/relay runs /usr/bin/node, so the install should use /usr/bin/npm too, with a RELAY_NPM override for tests like RELAY_INSTALL_ROOT.
