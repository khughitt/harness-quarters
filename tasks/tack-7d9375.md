Outcome: an opt-in way to randomly assign one factor (harness, model, reasoning effort, or a skill/flow variant) when a task is started, recorded on the task as randomized with the arm, so obs comparisons over those tasks can support causal claims that historical data cannot. Covers eligibility (which tasks may be randomized), how the arm reaches the harness, and a stopping rule. Optional extension for small tasks: two arms implement the same task and are judged blind.
