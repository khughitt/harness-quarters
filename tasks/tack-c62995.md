Observed during ai-45ac4c: the agent repeatedly parked a claimed, unblocked implementation task between ordinary red-green increments because end-of-turn/task-bookkeeping guidance was interpreted as requiring a pause. Define the intended rule for continuing an active task across turns, including when parking is actually appropriate, and revise upstream guidance/skills so normal implementation continues until a real blocker, review gate, or user decision.
