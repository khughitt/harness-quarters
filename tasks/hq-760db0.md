Why: hq sessions names each cwd by its tasks project prefix (hq-3520b9); the user wants that name in the project's colour, as every tool that names a project should show it (ops-30b965).

Approach: read the colour through the tasks CLI (the JSON that tasks-b124ab asks for, e.g. a color field on tasks resolve rows), never by parsing tasks/.config.toml or the registry. Paint only the prefix; keep the @worktree dimmed and the path fallback uncoloured. Under 256 colours use the source's stand-in. Keep hq's colour rules: --color auto|always|never, NO_COLOR, padding outside the codes, and stripping codes gives the plain listing exactly.

Done when tests cover a coloured prefix at both depths, a project without a colour staying plain, and strip-equals-plain; README documents it; the user has looked at a real listing.
