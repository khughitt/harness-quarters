facts/capabilities.toml records the version each fact was probed on; nothing compares it with what is installed. The claim guard trusts a wake fact probed on an older Claude Code. From the residue design §4.6.

Scope 2026-10-08: already true on this host. Installed are Claude Code 2.1.294 and Codex 0.161.0; every entry was probed on 2.1.282/2.1.284 and 0.156.1. Codex's controller-wake = false is live: ops claim-guard mirrors it as CHILD_WAKES, the global Processes rule cites it, and docs/notes/2026-10-08-codex-long-waits-brief.md builds on it.

Decisions left (brief: docs/notes/2026-10-08-declared-surface-drift-brief.md): who compares and when (lean: a harness-facts stale command plus a warning in just test, over a staleness flag on every read or an upgrade hook); whether any version change counts or only minor/major; whether a stale fact changes a consumer or is only reported (lean: report only). Waits on hq-b2515c, the re-probe on the installed versions, which shows whether values move.
