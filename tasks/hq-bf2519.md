An agent looking for a file a skill's relative link names ran a recursive file search over the shared skills directory and got no results, then reported the file as missing although it sits inside the linked skill directory. The declared links install each skill as a directory symlink, and rg (like fd and find without -L) skips symlinked directories by default, so any search rooted at the skills directory is silently empty. Expected: either a layout or capability fact that says searches there need -L/--follow, or a layout a default search traverses.
