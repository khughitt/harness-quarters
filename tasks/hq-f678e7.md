A Codex collaboration follow-up returned only an agent error saying the selected model was at capacity and to try another model. Inspection by a replacement worker found that the original worker had already committed the requested correction, completed verification, saved its report and released its task claim. The terminal failure notification therefore hid completed work and encouraged duplicate dispatch; completion/error reporting should preserve partial or completed outcomes so the controller can distinguish failure before execution from failure after handoff.
