One way to locate, parse, and summarize each coding agent's local session store: Claude Code, Codex, opencode, and Crush. Deliverables are a skill that tells an agent where each store lives and how to read it, plus the tooling the skill leans on.

Open choice: per-agent helper scripts, or one shared CLI. ops already ships bin/obs-index (ops-1a77f4), a read-only indexer over the Claude Code and Codex stores with dedupe rules for resume files; extend it to opencode and Crush rather than writing a second parser, and let the skill be the thin layer that explains and invokes it.
