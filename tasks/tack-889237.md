Agents commit superpowers specs and plans (docs/superpowers/specs/, docs/superpowers/plans/) to public repositories we do not maintain and to work repositories that never asked for them; a reviewer had to ask for one to be moved off a PR branch. The brainstorming skill says 'commit the design document' and nothing in AGENTS.md counters it. Rule: default off everywhere, including personal projects; a checkout opts in when its own AGENTS.md/CLAUDE.md names where design docs live, or the user says so in the session. Uncommitted docs are written at the expected path and kept out of the tree via .git/info/exclude.
