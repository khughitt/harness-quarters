Context: `hq-4407a2` set `{"defaultMode": "off"}` in `~/.config/ponytail/config.json`, stopping `ponytail-activate.js` (`SessionStart`) and `ponytail-subagent.js` (`SubagentStart`) from auto-injecting Ponytail's `role: developer` ruleset. However, because `[plugins."ponytail@ponytail"] enabled = true` remains set in Codex and Claude Code, the `ponytail` skill (`"Use on any coding task..."`) stays in the skill catalog. As observed in Codex rollout `01a1ab04` (lines 5 & 19), agents on coding tasks explicitly read `~/.codex/plugins/cache/ponytail/ponytail/<version>/skills/ponytail/SKILL.md`, where line 15 still instructs: `End your reply with one or two lines: what you skipped or did not check, and any risk the user must know.`

Trigger: Activate if `obs-494be5` / `obs-6f0fd2` shows coding turns still emitting `Skipped:` footers after `hq-4407a2` and `lore-039504`; either vendor/override Ponytail's `SKILL.md` without the mandatory skipped-work footer line or disable the upstream plugin in favor of a tracked skill.
