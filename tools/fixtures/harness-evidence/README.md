# Index evidence controls

The ordinary reader catalogue remains in `../session-logs/`. `CATALOGUE.toml`
contains only implemented index-profile controls; it does not claim reader roles.
All new controls here are synthetic. An original test's version comment describes
that case's provenance, not an observed emission or support claim.

`codex-basic.jsonl` copies the minimal original constants and record constructors
listed in `codex-controls.json` from the frozen OBS source. That control file pins
its source and ordinary reader outputs. `codex-conformance.json` inventories each
original test identity, assertions, boundary and later task owner. A pending entry
is required future work, never evidence of support. In mixed cases HQ owns native
interpretation while OBS keeps measurement and table projection assertions.

Task 1 supplies direct records, usage arithmetic/presence, context, origin, bytes,
direct shell input/directory and lexical patch candidates. Task 2 owns output
status/truncation, skill inference, code-mode operations, bounded pending state,
identity metadata, late associations and usage/context replay replacement. Its
256-entry recent bounds and 1,000 ms matching slack are pinned in the inventory.
Unlisted or unknown versions are untested; synthetic controls prove conformance,
not observed emission. No private live transcript is copied here.
